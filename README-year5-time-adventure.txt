Year 5 24-Hour Time Quest

Open year5-time-adventure.html in any modern web browser to play.

What is included:
- A Roblox-style block adventure game for Year 5 pupils.
- 24-hour clock questions from easy to hard.
- Question types: what time, how long, start time, and finish time.
- Teacher dashboard with pupil activity, marks, mistakes, print, save as PDF, and CSV export.
- Completion certificate with pupil name and score.
- Built-in music and answer sound effects.

To save as PDF:
1. Open the Teacher Dashboard or Certificate screen.
2. Select Print or Save PDF.
3. Choose Save as PDF in the browser print window.

No internet connection is required.
